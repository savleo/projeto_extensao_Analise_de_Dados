Análise de Dados dos Servidores da Prefeitura de Ipatinga-MG

Este projeto teve como objetivo analisar os dados salariais dos servidores da Prefeitura de Ipatinga-MG, utilizando técnicas de exploração, tratamento e visualização de dados. 

Através da linguagem Python e bibliotecas como Pandas e Matplotlib, foram extraídas estatísticas descritivas relevantes, permitindo identificar padrões salariais, dispersões e discrepâncias entre os setores públicos.

Principais atividades desenvolvidas:
✔ Coleta e pré-processamento de dados – Tratamento de valores ausentes e eliminação de inconsistências.
✔ Análise estatística – Cálculo de medidas centrais (média, mediana) e de dispersão (desvio padrão, amplitude, variância e coeficiente de variação).
✔ Visualização de dados – Construção de gráficos de distribuição e boxplots para compreensão da variação salarial entre setores.
✔ Identificação de insights – Comparação entre secretarias e unidades administrativas para evidenciar discrepâncias e tendências.

Relevância do projeto:
A análise desses dados fornece informações valiosas para a gestão pública, permitindo uma maior transparência sobre a distribuição dos recursos municipais. Além disso, a identificação de padrões salariais e variações entre setores pode auxiliar na formulação de políticas mais equitativas, no planejamento orçamentário e na melhoria da gestão de pessoal. Esse estudo também demonstra a importância da análise de dados na tomada de decisões estratégicas, reforçando a necessidade de profissionais capacitados na área.

Com esse projeto, reforcei habilidades em análise exploratória de dados (EDA), estatística descritiva, manipulação de dados com Pandas e visualização de informações importantes.
